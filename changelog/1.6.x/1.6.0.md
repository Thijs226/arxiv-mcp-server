# 1.6.0 — 2026-10-17

## Added

- **`arxiv_read_paper` `outline`** — section headings of the cleaned body, each with `level`, `title`, and the `start` that reads from it; returned on the first page only, empty for `pdf_text`. Past 200 headings the deepest levels drop (`outline_omitted_levels`); a single level over 200 keeps its first 200 and `outline_continues_at` names the `start` to read on from (#44).
- **`arxiv_get_metadata` `remaining_ids`** — `paper_ids` takes up to 100 IDs, looks up the first 10 well-formed ones, and returns the rest in canonical form to pass to the next call (#51).
- **ID spellings** — `arxiv_get_metadata`, `arxiv_read_paper`, and `arxiv://paper/{paperId}` accept an `arXiv:` prefix and arxiv.org `abs`, `pdf`, and `html` URLs (scheme optional; trailing slash, `?query`, and `#fragment` ignored). Uppercase archives and old-style subject classes normalize (`math.GT/0309136` → `math/0309136`) (#41).
- **`invalid_id`** — a typed error on those three surfaces and a `not_found[].reason` value on `arxiv_get_metadata` (#41).
- **`start_beyond_result_limit`** — typed error on `arxiv_search_papers` for a `start` of 10,000 on a search the live API answers (#56).

## Changed

- **`arxiv_search` is renamed `arxiv_search_papers`, with no alias** — callers update the tool name (#46).
- **With the local mirror enabled, a search whose free-text terms match 50,000 or more mirror papers is answered by the live API** (#49), which serves only the first 10,000 results of a query (#56): such a search refuses `start` = 10,000 (`start_beyond_result_limit`) and cuts a page that would cross result 10,000. 1.5.4 served those deep pages from the mirror. No mirror search counts or ranks more than 50,000 matches; a live failure on such a search is returned, never answered from the mirror.
- **`arxiv_search_papers` `max_results`** accepts up to 10,000 and serves at most 50 per call; a larger value returns 50, and the truncation notice names the next `start`, or date windows once paging cannot reach every match (#51).
- **`arxiv_get_metadata` `paper_ids`** advertises an array; a lone string is still accepted as one ID (#51).

## Fixed

- **`arxiv_read_paper` body** ends at the last `</article>` — site header and footer go, appendices and bibliography stay — and relative `src`, `href`, and `data` URLs resolve against the URL that served the page; `#fragment` links stay as written (#43).
- **Cleaning passes** (article cut, MathML collapse, class and id stripping, URL resolution, outline scan) are linear in page length (#52).
- **ar5iv conversion-failure page** — a 200 holding only LaTeXML's fatal-error notice falls through to the PDF; the check is linear in page length (#54).
- **Atom text stays text** — a title of `1.10` or a comment of `0` is no longer parsed as a number (#45).
- **Malformed IDs** fail `invalid_id` before any request: an archive that never issued old-style IDs (`hepth/9901001`), the wrong sequence width for the era (`1706.0376`, `0703.12345`), and non-arXiv strings (#41).
- **Live search** never requests past result 10,000: a page crossing it is cut there with the cut disclosed, and `start` 10,000 is refused where it was an HTTP 500 (#56).
- **A cancelled live search** is no longer answered from the mirror on the recency bypass.
- **Mirror relevance order** — a relevance-sorted search the mirror answers ranks by BM25, best match first, where 1.5.4 returned matches in harvest order; ties break by row id, so pages never overlap (#49).
- **Mirror refresh** stops starting pages once a worst-case page cycle no longer fits `ARXIV_MIRROR_REFRESH_TIMEOUT_MS`, checkpoints, and reports a `partial` outcome (logged at notice) instead of being killed and logged as a failed job (#39). The next run resumes from the saved resumption token, or from the latest applied datestamp when arXiv rejects the token (#50).
- **Mirror writes** — the harvest runner creates the `paper_categories(paper_id)` index before its first page; the schema version is unchanged (#50).
